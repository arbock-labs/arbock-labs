## Selected work

### 1. SHERLOCK — Chess analysis environment
**[Source repository](https://github.com/lughlammas/sherlock)** · [Android v0.1.3 release](https://github.com/lughlammas/sherlock/releases/tag/v0.1.3)

A visual chess investigation environment connecting a React/TypeScript interface, a WebSocket controller, a classical UCI adapter, and a native chess engine. Includes an Android WebView/native-process integration.

**Engineering focus:** frontend, event-driven communication, process control, UCI protocol, session handling, and desktop/Android integration.

**Scope note:** the documented integration uses Lughnasadh **0.2**, not the separate 0.4.0 engine. Native analysis requires the relevant executable; the README does not claim an independent performance benchmark or retested device support.

### 2. Lughnasadh 0.4.0 — Fourth Harvest
**[Source repository](https://github.com/lughlammas/lughnasadh)** · [Technical validation](https://github.com/lughlammas/lughnasadh/blob/main/docs/TECHNICAL_VALIDATION_0.4.md) · [MIT license](https://github.com/lughlammas/lughnasadh/blob/main/LICENSE)

An original C++20 classical UCI chess engine, with legal move generation, position representation, evaluation, search, transposition tables, CMake builds, and perft checks.

**Engineering focus:** systems programming, search algorithms, protocol implementation, deterministic validation, and regression testing.

**Scope note:** the linked validation concerns a specifically identified 0.4 artifact. It does not establish an absolute Elo rating or validate subsequent changes. The original copyright and MIT terms remain with the source repository.

### 3. comercial-template — Commercial workflow application
**[Source repository](https://github.com/lughlammas/comercial-template)** · [Product walkthrough](https://github.com/lughlammas/comercial-template/blob/main/docs/PRODUCT_WALKTHROUGH.md)

A Next.js/TypeScript demonstration application for customer records and commercial proposals, with authentication, user-scoped Prisma persistence, PDF generation, Docker configuration, and documented testing.

**Engineering focus:** full-stack web development, data models, authorization boundaries, document generation, and testable business workflows.

**Scope note:** this is a demonstration application with synthetic seed data; production security, hosting, and commercial adoption are not claimed. The source repository has **no LICENSE file**; public visibility does not grant permission to copy or relicense it.

### 4. Êxodus — Android file manager
**[Source repository](https://github.com/lughlammas/exodus)** · [Android v1.0.0 release](https://github.com/lughlammas/exodus/releases/tag/v1.0.0) · [MIT license](https://github.com/lughlammas/exodus/blob/main/LICENSE)

A Kotlin Android application for local file browsing, folder management, ZIP creation, and system sharing, without advertising.

**Engineering focus:** native Android, local file operations, storage permissions, user interface, and packaging.

**Scope note:** the project requests broad file access for supported operations. Its README does not claim a current automated CI/test suite or a newly retested device build.

### 5. AI Coordinator Portfolio — Human-directed AI delivery methodology
**[Source repository](https://github.com/lughlammas/ai-coordinator-portfolio)** · [Workflow overview](https://github.com/lughlammas/ai-coordinator-portfolio/blob/main/docs/HUMAN_DIRECTED_AI_WORKFLOW.md) · [MIT license](https://github.com/lughlammas/ai-coordinator-portfolio/blob/main/LICENSE)

A documentation toolkit with role definitions, playbooks, prompts, acceptance criteria, handoffs, and decision records for coordinating AI-assisted software work under human supervision.

**Engineering focus:** requirements, agent/tool coordination, QA, traceable delivery, and reproducible handoffs.

**Scope note:** the repository contains reusable methodology, **not** an executable multi-agent platform. Its consolidation case study concerns self-directed work, not a paid client engagement.
