# ARBOCK LABS

**Independent Software & Applied AI Studio**  
*We turn problems into working software.*

We are an independent software studio building practical digital tools, business automations, and AI-assisted workflows. Our focus is straightforward: understand the problem, build a working solution, and improve it through real feedback.
